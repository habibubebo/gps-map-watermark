# 🎯 START HERE - Panduan Memulai

Selamat datang di **Image Watermark Pro**! 👋

Aplikasi ini memungkinkan Anda menambahkan watermark GPS, waktu, dan cuaca pada gambar dengan mudah.

---

## ⚡ Quick Start (2 Menit)

### 1️⃣ Buka Aplikasi
```
Double-click file: index.html
atau
Buka dengan browser: Chrome, Firefox, Safari, Edge
```

### 2️⃣ Upload Gambar
- Klik area upload atau drag-drop gambar
- Format: JPG, PNG, WebP

### 3️⃣ Tambahkan Watermark
- Centang "Tampilkan GPS" → Klik "Ambil Lokasi"
- Centang "Tampilkan Waktu" → Pilih format
- Centang "Tampilkan Cuaca" → Masukkan kota

### 4️⃣ Download
- Klik "Download Gambar"
- File PNG siap digunakan!

## 🎨 Fitur Utama

### 📍 GPS Watermark
- Tampilkan koordinat latitude & longitude
- Ambil lokasi otomatis atau input manual

### 🕐 Waktu Watermark
- Tampilkan tanggal dan waktu
- 3 format pilihan: Lengkap, Tanggal, Waktu

### 🌤️ Cuaca Watermark
- Tampilkan kondisi cuaca dan suhu
- Cari berdasarkan nama kota

### 🎨 Kustomisasi
- Ukuran font, warna, transparansi
- 4 posisi: Bawah Kiri, Bawah Kanan, Atas Kiri, Atas Kanan

### 💾 Template System
- Simpan pengaturan sebagai template
- Kelola multiple template
- Setiap template berbeda pengaturan

## ❓ Pertanyaan Umum

**Q: Apakah perlu instalasi?**
A: Tidak! Cukup buka index.html di browser.

**Q: Apakah gambar dikirim ke server?**
A: Tidak! Semua proses di browser Anda.

**Q: Apakah perlu internet?**
A: Hanya untuk fitur cuaca. GPS dan waktu bisa offline.

**Q: Bagaimana jika lupa template?**
A: Template tersimpan di browser. Jangan hapus cache!

**Q: Bisa di mobile?**
A: Ya, tapi lebih nyaman di desktop.

## 💡 Tips Profesional

1. **Font Size**: 16-18px paling bagus
2. **Warna**: Putih di background hitam paling kontras
3. **Posisi**: Hindari menutupi subjek utama
4. **Template**: Buat template untuk setiap use case
5. **Backup**: Backup template secara berkala
