# 🚀 Quick Start Guide

## Langkah 1: Buka Aplikasi
1. Buka folder `gps-map-watermark` di komputer Anda
2. Double-click file `index.html` atau buka dengan browser favorit Anda
3. Aplikasi akan langsung siap digunakan (tidak perlu instalasi)

## Langkah 2: Upload Gambar
1. Klik area upload atau drag-drop gambar ke area tersebut
2. Gambar akan ditampilkan di preview

## Langkah 3: Konfigurasi Watermark

### Opsi A: Gunakan Template Default
1. Buka tab "Pengaturan Template"
2. Sesuaikan pengaturan sesuai kebutuhan
3. Klik "Simpan Template" untuk menyimpan

### Opsi B: Gunakan Template yang Sudah Ada
1. Klik template di sidebar kiri
2. Pengaturan akan otomatis dimuat

## Langkah 4: Aktifkan Fitur yang Diinginkan

### GPS
- ✅ Centang "Tampilkan GPS"
- Klik "📍 Ambil Lokasi Saat Ini" untuk geolocation otomatis
- Atau input manual latitude/longitude

### Waktu
- ✅ Centang "Tampilkan Waktu"
- Pilih format: Lengkap / Tanggal Saja / Waktu Saja

### Cuaca
- ✅ Centang "Tampilkan Cuaca"
- Masukkan nama kota (contoh: Jakarta, Bali, Surabaya)
- Klik "🌤️ Ambil Cuaca Saat Ini"

## Langkah 5: Kustomisasi Tampilan

1. **Ukuran Font**: Geser slider atau input angka (8-48px)
2. **Warna Teks**: Klik color picker untuk pilih warna
3. **Warna Background**: Klik color picker untuk pilih warna
4. **Transparansi**: Geser slider (0-100%)
5. **Posisi**: Pilih dari dropdown (Bawah Kiri, Bawah Kanan, dll)

Preview akan update secara real-time!

## Langkah 6: Download Gambar
1. Klik tombol "⬇️ Download Gambar"
2. Gambar akan diunduh dengan watermark

## Langkah 7: Simpan Template (Opsional)
1. Masukkan nama template di field "Nama Template"
2. Klik "💾 Simpan Template"
3. Template akan tersimpan dan bisa digunakan lagi

---

## 💡 Contoh Cepat

### Watermark Liburan
```
1. Upload foto liburan Anda
2. Aktifkan GPS → Klik "Ambil Lokasi Saat Ini"
3. Aktifkan Waktu → Format: Lengkap
4. Aktifkan Cuaca → Masukkan kota tujuan
5. Posisi: Bawah Kanan
6. Download!
```

### Watermark Dokumentasi
```
1. Upload dokumen/screenshot
2. Aktifkan GPS → Input manual lokasi kantor
3. Aktifkan Waktu → Format: Tanggal Saja
4. Nonaktifkan Cuaca
5. Font: 14px, Warna: Putih, Background: Biru
6. Posisi: Atas Kiri
7. Download!
```

## ❓ FAQ Cepat

**Q: Apakah perlu internet?**
A: Ya, untuk mengambil data cuaca. GPS dan waktu bisa offline.

**Q: Apakah gambar dikirim ke server?**
A: Tidak! Semua proses di browser Anda sendiri.

**Q: Bisa di mobile?**
A: Ya, tapi lebih nyaman di desktop.

**Q: Bagaimana jika lupa template?**
A: Template tersimpan di browser. Jangan hapus cache browser!

**Q: Bisa export template?**
A: Belum, tapi bisa dibuat di versi mendatang.

## 🎯 Tips Profesional

1. **Font Size**: 16-18px paling bagus untuk kebanyakan gambar
2. **Transparansi**: 70% cocok untuk background gelap
3. **Posisi**: Hindari menutupi subjek utama foto
4. **Warna**: Putih di background hitam paling kontras
5. **Cuaca**: Gunakan nama kota dalam bahasa Inggris
