## 📍 Format GPS

```
Latitude: -6.2088 (negatif = selatan)
Longitude: 106.8456 (positif = timur)

Contoh Lokasi:
Jakarta: -6.2088, 106.8456
Bali: -8.6705, 115.2126
Surabaya: -7.2575, 112.7521
Yogyakarta: -7.7956, 110.3695
```

## 🐛 Troubleshooting Cepat

| Masalah | Solusi |
|---------|--------|
| Aplikasi tidak buka | Refresh (Ctrl+R) |

## ⚡ Performance Tips

1. **Gunakan gambar ukuran wajar** (max 4000x3000)
2. **Font size 16-18px** paling optimal
3. **Transparansi 70%** cocok untuk kebanyakan kasus
4. **Tutup tab lain** untuk performa lebih baik
5. **Refresh browser** jika lag

---

## 🔐 Security Tips

1. **Jangan bagikan browser** dengan orang lain
2. **Jangan hapus cache** jika ingin keep template
3. **Gunakan HTTPS** jika di server
4. **Backup template** secara berkala
5. **Jangan upload** gambar sensitif

---

## 📞 Quick Help

**Aplikasi tidak buka?**
- Refresh: Ctrl+R
- Clear cache: Ctrl+Shift+Delete
- Coba browser lain

**Geolocation tidak bekerja?**
- Izinkan akses lokasi
- Cek pengaturan privacy
- Gunakan HTTPS jika di server

**Cuaca tidak ditemukan?**
- Cek ejaan kota
- Gunakan bahasa Inggris
- Coba kota yang lebih besar

**Template hilang?**
- Jangan hapus cache browser
- Cek IndexedDB di DevTools
- Buat template baru
